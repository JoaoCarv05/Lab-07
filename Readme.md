# Laboratório 7 – Introdução às Redes CNN

**ESZA019 – Visão Computacional — 2026.2**

## Descrição

Este repositório contém o relatório do Laboratório 7 da disciplina de Visão Computacional, focado na **Introdução às Redes Neurais Convolucionais (CNN)** para reconhecimento em imagens. O roteiro aborda a transição dos filtros espaciais clássicos (Sobel, Gaussiano) para os filtros aprendidos por uma CNN, a construção e o treinamento de uma rede compacta em **TensorFlow/Keras** e a inspeção dos *feature maps* das camadas convolucionais.
